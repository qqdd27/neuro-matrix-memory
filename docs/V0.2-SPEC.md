# NeuroMatrix Memory — v0.2 Specification

Consolidated scope of everything agreed for the next release of the
`neuromatrix` Hermes memory provider (repo root `D:\WEB\neuro-matrix-memory`).
Goal: durable **intent + decision knowledge**, contradiction-safe logic,
**token economy at scale** — while staying local-first, zero-dependency,
LLM-optional.

---

## 0. Schema migration (idempotent, old DBs keep working)

SQLite has no `ALTER TABLE ... ADD COLUMN IF NOT EXISTS` — migrations inspect
`PRAGMA table_info(facts)` first, then add.

```sql
ALTER TABLE facts ADD COLUMN kind        TEXT    NOT NULL DEFAULT 'episodic';
ALTER TABLE facts ADD COLUMN active_until REAL;             -- NULL = бессрочно
ALTER TABLE facts ADD COLUMN supersedes  INTEGER REFERENCES facts(id); -- эволюция решения
ALTER TABLE facts ADD COLUMN confidence  REAL    NOT NULL DEFAULT 1.0;
CREATE INDEX IF NOT EXISTS idx_facts_kind   ON facts(kind);
CREATE INDEX IF NOT EXISTS idx_facts_active ON facts(active_until);
CREATE INDEX IF NOT EXISTS idx_facts_supersedes ON facts(supersedes);
```

New kinds: `episodic` (legacy default) · `decision` · `goal` · `constraint` ·
`lesson` · `correction` · `episode` · `artifact` (pointer fact).

New table:

```sql
CREATE TABLE IF NOT EXISTS artifacts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    kind TEXT NOT NULL DEFAULT 'document',
    topic TEXT,                -- one-line indexable description
    sha256 TEXT NOT NULL UNIQUE,   -- content dedupe
    size INTEGER NOT NULL,
    path TEXT NOT NULL,        -- sidecar file: $HERMES_HOME/neuromatrix/artifacts/<sha256>
    head TEXT,                 -- first ~500 chars for entity extraction / snippets
    fact_id INTEGER REFERENCES facts(id) ON DELETE SET NULL, -- unified-search pointer
    created_at REAL NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_artifacts_sha ON artifacts(sha256);
CREATE INDEX IF NOT EXISTS idx_artifacts_fact ON artifacts(fact_id);
```

Artifact **payloads live in files, not SQLite** (blobs bloat the WAL). An
`artifact` fact (short summary text + `meta.artifact_id`) makes the artifact
findable by the existing unified search.

Meta keys (daily LLM budget, prune bookkeeping): `llm_budget_day`,
`llm_budget_used`, existing `last_prune_day`.

## 1. Intent ledger — goals / constraints (Context-Unrolling need, honest version)

**What:** durable `goal | constraint` facts about the user's projects and plans
("в планах мобильное приложение после сайта", "данные first-party only").

**Write path:**
- tool actions `remember_goal(text, entity?)` / `remember_constraint(...)`;
- automatic: `on_session_end` LLM-assisted review (when a key is configured)
  extracts goals/constraints/decisions from the session — Dreaming-style;
  without LLM the user/agent records them explicitly only.

**Lifecycle:** goals/constraints never decay (see §3); changing a goal =
new fact + `active_until` on the old one (never overwrite).

---

## 2. Decision evolution (Supabase → Firebase pattern)

**What:** decisions are `kind=decision` facts with a validity window; switching
keeps the full reasoning trail and produces a durable **lesson**.

**API (store):**
- `decide(concept_entity, choice, criteria: list[str], scope_tags: list[str])`
  → active `decision` fact; criteria are **structured tags**, not prose
  (this is the scope guard: a lesson only fires when criteria overlap).
- `supersede(decision_fact_id, new_choice, criteria, scope_tags)`
  → old fact gets `active_until = now`; new fact gets
  `supersedes = old_id`; **no separate evolution_logs table** — the trail
  IS the chain of `supersedes` facts.
- `decisions(concept_entity)` → current active + full trail.

**Lesson synthesis (consolidation phase, LLM-optional):**
- with LLM: reflect over the supersede chain →
  `kind=lesson` fact, e.g. "Всегда проверять offline-требования ДО выбора БД",
  tagged with the union of criteria (weight high);
- without LLM: lesson = structured diff
  `old{criteria} → new{criteria}` (still queryable, no prose invented).

**Retrieval effect:** `probe(entity)` returns current decision + trail +
lesson; a NEW `decide` with overlapping criteria surfaces the lesson (agent
then asks the "offline критичен?" question itself — no templates).

---

## 3. Per-kind lifecycle / decay policy

Hindsight rule: *decay only temporal claims — blanket decay throws away
stable facts.*

| kind | decay | dies by |
|---|---|---|
| `episodic` | recency-weighted ranking + prune (as today) | time |
| `episode` (rollup) | as `episodic` | time |
| `decision/goal/constraint` | **none** | `supersedes` / explicit |
| `lesson/correction` | **none**, confidence-weighted | explicit |
| `artifact` | **none** | explicit `forget` |

Implementation: scoring fns branch on `kind`; prune skips durable kinds.

---

## 4. Correction detection at write

**What:** "нет, не так — мы выбрали Firebase" right after an assistant claim
is the single highest-value signal; today it just becomes another fact.

**Implementation (deterministic, no LLM):** RU/EN negation patterns
(`нет, не так|на самом деле|actually|no, it's|не X, а Y|это ошибка|wrong|вместо`)
+ entity overlap with the previous assistant fact of the same session →
  previous fact gets `confidence *= 0.3` + `active_until = now` (if same
  claim space) or `kind=correction` marker linking both; consolidation folds
  the corrected pair into the dossier ("X → Y, because ...").

---

## 5. Contradiction scan (action `contradict`)

**What:** find currently-active facts/dossiers that conflict.

- without LLM: structural scan — same entity, overlapping criteria, two active
  `decision`/durable facts with different choices (list for review);
- with LLM: batched resolution proposal (which is current, why) — never
  auto-deletes, always proposes + marks after confirmation.

---

## 6. Confidence + feedback reinforcement

- new column `confidence` (default 1.0);
- effective retrieval weight = `importance × confidence × recency-kind-factor`;
- tool action `feedback(fact_id, helpful|unhelpful)`:
  `helpful → confidence +0.15 (cap 1.5)`, `unhelpful → ×0.5`, repeated
  unhelpful (`< 0.2`) archives the fact;
- corrections (§4) are the automatic form of negative feedback.

---

## 7. Point-in-time queries (`as_of`)

- `search(query, as_of=ts)` honors `active_until`/`ts`: answers "что было
  верно на 1 марта" vs "что верно сейчас";
- results on superseded items render `[заменено → <new choice>]` (join via
  `supersedes` reverse lookup);
- `recall_status`/prefetch always uses "now" (current truth).

---

## 8. Episode rollups (session layer)

- `on_session_end`: create one `kind=episode` fact per session —
  `"Сессия <id>: темы [entities], решения [n], итог"`, token-capped (~600
  chars), entity-linked, meta stores message count;
- narrative recall ("что мы делали в тот день про TON") + better,
  already-deduplicated input for consolidation;
- `on_pre_compress` micro-rollup when a session runs long.

---

## 9. Action `ask` — synthesized answer + explicit unknowns (the honest "Prompt Expander")

With LLM only. Input: query + retrieved dossiers/trail/lessons. Output
(≤ ~400 tokens):
```
current answer (2–3 sentences, citing memory)
unknowns: [criteria never recorded — e.g. offline requirement]
```
Unknowns derive from comparing criteria of past decisions with the current
context — this is the mechanism that makes the agent *ask back* the right
question without any template bank. Without LLM → plain facts (today's path).

---

## 10. LLM rerank (optional)

- `search(..., rerank=True)` (needs key + within daily budget): score top-20
  by heuristics → LLM picks top-5 for the query;
- prefetch keeps heuristic-only (must be instant and free).

---

## 11. Artifacts layer — big data without token cost

- `store_artifact(name, kind, text|file_path)`:
  - sha256 dedupe (duplicate → returns existing id);
  - payload → sidecar file `$HERMES_HOME/neuromatrix/artifacts/<sha256>`;
  - `head` = first 500 chars → entity extraction + summary fact
    (`kind=artifact`, `meta.artifact_id`) → found by unified search;
  - size guard: config `artifact_max_bytes` (default 100 MB).
- `artifact_get(id, max_chars=4000)` → head/snippet + absolute path; the
  agent reads the file itself only when actually needed (tokens only then);
- oversized returns respect Hermes `output_spill` (head/tail + path);
- never auto-deleted; `backup/restore` (§14) covers them.

---

## 12. Recall budget & score gate (token economy on the hot path)

- config `max_recall_chars` (default 1500): prefetch output truncated at
  sentence boundary;
- config `min_recall_score`: below threshold → return nothing (0 tokens,
  no noise — irrelevant recall disrupts reasoning);
- prefetch stays heuristic + LRU-cached (instant, free);
- `system_prompt_block` unchanged: 2–3 status lines, never facts.

---

## 13. Daily LLM budget

- config `llm_daily_budget` (default 20 calls/day) — shared counter across
  consolidation, rerank, `ask`, contradiction resolution;
- stored in `meta` (`llm_budget_day` / `llm_budget_used`), resets at UTC
  midnight; hard stop above budget (features degrade to extractive/heuristic).

---

## 14. Ops: CLI, ingest, backup/restore

- `cli.py` next to package `__init__.py` (`hermes neuromatrix ...`):
  - `status` — stats + budget used;
  - `search "query"` — CLI recall;
  - `consolidate [--force]` — run the sleep cycle;
  - **`ingest [--sessions N] [--days N]`** — cold start: read
    `$HERMES_HOME/state.db` (SQLite + FTS5) recent user/assistant rows →
    batched `add_turn` (fixes the empty-store problem on first activation);
  - `export <path.json>` / `import <path.json>` — full dump/restore
    (facts+entities+aliases+edges+dossiers+artifacts-metadata);
- `backup_paths()` includes the artifacts dir (outside-HERMES_HOME support).

---

## 15. Delegation learning + skills bridge

- `on_delegation(task, result, child_session_id)` (ABC hook exists): parent
  records `kind=lesson` "subagent approach for task X worked/failed — …"
  (importance 0.8) — no LLM needed, deterministic template + entity tags;
- durable procedures discovered during consolidation are surfaced as a
  **skills suggestion** (returned in the tool result, host decides) instead of
  bloating memory — Hermes skills are the right home for procedural memory.

## 16. Tool API (final v0.2 surface)

Single tool `neuromatrix`, actions:

| action | purpose |
|---|---|
| `search` | unified recall (facts, dossiers, trail, lessons), `as_of`, `rerank` optional |
| `remember` | episodic fact |
| `remember_goal` / `remember_constraint` | durable intent |
| `decide` | record a decision (choice + criteria tags) |
| `supersede` | change a decision → trail + lesson hook |
| `decisions` | current + evolution trail for a concept |
| `probe` | entity profile (aliases, dossier, decisions, unknowns) |
| `link` | merge aliases |
| `ask` | LLM-synthesized answer + explicit unknowns (key only) |
| `contradict` | contradiction scan |
| `feedback` | reinforce / decay a fact |
| `artifact_store` / `artifact_get` | big-data layer |
| `consolidate` | run the sleep cycle |
| `stats` | size + budget counters |

## 19. Confirmed frontier additions (v0.3 — "truth & time" + "memory policy")

Research digest and full rationale: `FRONTIER-RESEARCH.md`. Confirmed by owner
2026-09-07 ("лучший плагин по памяти, просто максимально"). Added to the
master plan:

- **§19.1 Atomic claims + citations (EMem, 2511.17208)** — sentence-level
  split at write: one `fact` = one claim; every hit carries
  `[fact #id, session sN]`; retrieval returns bundled evidence (claims +
  source turns), enabling grounded, verifiable answers.
- **§19.2 Agentic `ask` with evidence-gap tracker (MemR3, 2512.20237)** —
  closed loop: retrieve → assess "can I answer? what lacks evidence?" →
  one targeted re-retrieval (max 2 rounds) → answer lists gaps explicitly.
  Without LLM the gap list is structural (criteria present in past decisions,
  absent in current context).
- **§19.3 Foresight signals (EverMemOS, 2601.02163)** — `kind=foresight`
  with `trigger_at` window; surfaced on topic reappearance or when due;
  optional Hermes-cron reminder bridge (`hermes neuromatrix remind`).
- **§19.4 Memory-ops log — RL-ready policy interface (Memory-R1,
  2508.19828; Agentic Memory, 2601.01885)** — every mutation appends
  `{op: ADD|UPDATE|DELETE|NOOP|SUPERSEDE, fact_id, ts, reason}`; default
  policy = heuristics + optional cheap-LLM decisions; NOOP default (cost
  control); trained policy can slot in later behind the same ops log.
- **§19.5 (v0.4) Procedures→skills** (`kind=procedure` outcome-tagged;
  success → skills suggestion), **shared scopes + audit** (private/shared,
  workspace_id, provenance audit view), **profile card + markdown mirror**
  (reviewable, editable memory folder), **MCP memory surface** (same core
  behind an MCP server).

## 22. Neurobiology grounding & adopted deltas (owner-approved 2026-09-07)

Neuroscience review (CLS, SHY, reconsolidation, surprise-driven selection).
Mapping: LTP/Hebbian → weighted `edges` ✅; hippocampus/neocortex (CLS,
McClelland 1995) → raw `facts` vs semantic `dossiers` ✅ (interleaved replay in
consolidation = CLS replay); sleep replay → `consolidate()` ✅; associative
spreading activation → 2-hop retrieval + budgeted prefetch ✅.

Adopted deltas (not yet implemented — fold into Milestone 2 / consolidation
upgrade):

- **§22.1 Reconsolidation on retrieval**: `facts.retrieval_count` (new col,
  default 0); every search hit increments it and touches the fact's edges
  (saturating cap so popularity cannot swamp relevance). Source: reconsolidation
  (retrieval re-opens the lability window).
- **§22.2 Inhibition on supersede**: `supersede()` additionally marks edges
  (concept_entity, old_choice_entity) with `inhibited_since REAL`; retrieval
  downweights inhibited edges; the evolution trail renders them as
  "отклонено/archived". Source: pathway inhibition; fixes the gap where old
  associations keep resurfacing after a decision flip.
- **§22.3 Synaptic downscaling during sleep (SHY, Tononi & Cirelli 2003)**:
  `consolidate()` runs a proportional normalization pass
  (`edge_scale` config, default 0.95 per cycle) + replay-boost for edges of
  entities that were consolidated/retrieved in this cycle. Bounds unbounded
  `count` growth and score drift.
- **§22.4 Surprise-gated consolidation (Nemori 2508.03341)**: consolidate
  first the facts that contradict/extend an existing dossier or active
  decision ("surprise"); skip near-duplicates that merely confirm it.
  Deterministic proxy first (no dossier for the entity / negative signal /
  criterion mismatch), LLM-assisted later. Selective forgetting is the weakest
  competency in agent-memory benchmarks (MemoryAgentBench) — this is our
  differentiator.
- **§22.5 (optional, later) REM pass**: LLM-generated rare novel cross-links
  between distant dossiers ("dreaming", SCM NREM/REM).

Sources: CLS (McClelland, McNaughton, O'Reilly 1995); SHY (Tononi & Cirelli
2003); Tadros et al. 2022 Nat. Comm. (sleep-like replay in ANNs); SCM
(arXiv 2604.20943); Nemori (arXiv 2508.03341); "Episodic Memory is the Missing
Piece" position (arXiv 2502.06975); MemoryAgentBench (arXiv 2507.05257).

## 23. Learning-theory mechanisms (dopamine / prediction error) — Milestone 3

Biology-of-learning review (owner request 2026-09-07). Adopted mapping:
prediction-error/dopamine → corrections-on-write + `feedback()` +
supersede-inhibition; myelination/habits → planned edge stability protected
from downscaling (§22.3 synergy, reversible via supersede); collateral
sprouting/rerouting → already delivered by Milestone 2 inhibition + lesson
trail. Their schema (hippocampus/synapses/neocortex tables) duplicates our
facts/edges/dossiers; Cyrillic-blind regex and LIKE scans rejected.

Implemented (Milestone 3, tests 18/18):
- `feedback(fact_id, helpful)` — confidence +0.15 (cap 1.5) / ×0.5; repeated
  unhelpful <0.2 archives the fact; feedback journal in meta.
- Correction-on-write (`NEG_MARKERS`, RU+EN): negative markers + shared
  anchors cut confidence ×0.4 of the newest matching assistant/durable claim
  and flag `negated` (deterministic, no LLM).
- `contradictions()` — near-duplicate episodic claims per entity (Jaccard
  ≥0.62) + entities with ≥3 active durable intent facts; tool `contradict`.
- Intent tools: `remember_goal` / `remember_constraint` with optional entity.
- Tool actions now: search, remember, probe, link, decide, supersede,
  decisions, remember_goal, remember_constraint, feedback, contradict,
  consolidate, stats.
